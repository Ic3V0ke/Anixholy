# Anixholy

**Форк [anixapp](https://github.com/Maks1mio/anixapp) — десктопного клиента для просмотра аниме на базе платформы Anixart.**

Оригинальный проект и вся его основа — заслуга автора **[Maks1mio](https://github.com/Maks1mio)**. Этот форк переосмысляет внешний вид приложения и добавляет к нему набор функций для удобного просмотра.

> [!WARNING]
> Проект в бета-тестировании. Возможны ошибки и нестабильная работа.

> [!WARNING]
> Для авторизации нужен аккаунт Anixart.

---

## Что изменено в этом форке

### Дизайн — полностью переработан

Приложение переведено на единый визуальный язык в стиле печатного зина: чернильно-тёмный фон с растровой сеткой, бумажно-кремовые плоскости, киноварный акцент, жёсткие тени без размытия, толстые рамки и лёгкие повороты элементов.

- **Новая палитра и типографика** — Unbounded для заголовков, IBM Plex Sans для текста, JetBrains Mono для чисел и метаданных. Шрифты поставляются локально.
- **Страница аниме переделана с нуля** — бегущая строка с фактами о релизе, постер «на скотче» с жёсткой тенью и штампом возрастного рейтинга, крупный заголовок, жанры-теги, мета-таблица, карточка оценки.
- **Единый стиль по всему приложению** — титлбар, сайдбар, карточки, кнопки, вкладки, модальные окна, выпадающие списки, тултипы, скроллбар, лоадеры и плеер.
- **Живые взаимодействия** — при наведении элементы приподнимаются и тень растёт, при нажатии «вдавливаются» в собственную тень.

### Динамическая тема под аниме

Интерфейс перекрашивается под постер открытого тайтла: у «Магической битвы» приложение становится красным, у «Власти книжного червя» — синим. Оттенок берётся из постера, а насыщенность и светлота удерживаются в рабочем диапазоне, чтобы акцент всегда читался. Блёклые постеры тему не меняют. Работает поверх любой выбранной темы, включая пользовательские.

### Плеер

- **Встроен в главное окно.** Раньше просмотр открывался отдельным окном — теперь это экран внутри приложения. Полноэкранный режим, лобби и Discord-статус работают как прежде.
- **Превью кадров на таймлайне** — при наведении на полосу прогресса показывается кадр из этого места и таймкод.
- **Продолжение с места остановки** — позиция серии сохраняется и восстанавливается при следующем открытии.
- **Пропуск титров** — ближе к концу серии появляется предложение перейти к следующей с обратным отсчётом и кнопкой «Досмотреть». Если переключаться вручную, приложение запоминает момент титров конкретного тайтла и в следующий раз предложит переход там же.
- **Кнопка «Следующая серия»** в панели управления.
- **Таймер сна** — остановиться после текущей серии.
- **Буст громкости до 200%** и **ночной режим** — аниме часто сведено тихо, а компрессор выравнивает громкость: диалоги слышно, взрывы не бьют по ушам.
- **Горячие клавиши**: `Space` / `K` — пауза, `←` / `→` — 5 секунд, `J` / `L` — 10 секунд, `↑` / `↓` — громкость, `M` — звук, `F` — полный экран, `N` — следующая серия, `0`–`9` — переход по проценту.

### Главная

- **«Продолжить просмотр»** — лента недосмотренных серий с полосой прогресса прямо на постере.

### Совместный просмотр

- Вынесен в левое меню отдельным пунктом с индикатором активной комнаты.
- Исправлена **бесконечная загрузка при создании комнаты**: запросы к серверу лобби перенесены в основной процесс, добавлены таймауты и внятные сообщения об ошибках вместо вечного спиннера.

### Исправления

- **Устранены зависания интерфейса.** Приложение намертво вставало при переходе в «Обзор» и навигации. Причина: все изображения грузились через основной процесс без таймаутов и ограничения параллельных запросов — при медленном CDN процесс, обслуживающий окно, захлёбывался. Обложки теперь загружаются напрямую, а прокси получил таймаут, лимит одновременных загрузок и кэш неудач.
- **Discord Rich Presence при просмотре.** После переноса плеера в главное окно статус показывал «в главном меню» вместо названия аниме и серии — починено.
- Прочее: снижена нагрузка от кастомного скроллбара, убраны повторяющиеся запросы карусели «Обзора», добавлена защита от зацикливания при разборе ответов API.

## Возможности

### Контент и навигация

- **Главная** — лента аниме: Последние, Онгоинги, Анонсы, Завершённые, Фильмы
- **Страница релиза** — описание, рейтинг, жанры, кадры, комментарии, похожие тайтлы
- **Закладки** — Смотрю, Запланировано, Просмотрено, Отложено, Брошено
- **Профиль** — статистика, динамика активности, друзья, списки
- **Поиск** — по релизам, профилям и коллекциям с историей запросов
- **Коллекции** — тематические подборки
- **Уведомления** — всё в одном месте

### Видеоплеер

- Потоковое воспроизведение через **HLS**
- Несколько источников: Kodik, Sibnet, Collaps, Anilibria и другие
- Выбор озвучки и эпизода прямо в плеере
- Переход к следующему эпизоду с автоподбором альтернативной озвучки
- Полноэкранный режим и Picture-in-Picture

### Апскейлинг Anime4K

- Улучшение картинки в реальном времени через **WebGPU**
- 20 режимов, включая готовые пресеты
- Проверка доступности GPU перед включением

### Discord Rich Presence

- Статус: смотрит аниме, открыл профиль, просматривает меню
- Обложка релиза или аватар профиля
- Прогресс просмотра эпизода
- Интеграция с лобби: приглашение и число участников

### Темы оформления

- Встроенные: **Авто**, **Тёмная**, **Светлая**, **AMOLED**
- Редактор пользовательских тем с предпросмотром
- Динамическая подсветка под постер аниме

## Установка

Скачать установщик со страницы [Releases](../../releases) и запустить.

## Сборка из исходников

```bash
yarn install
yarn build:win
```

Готовый установщик появится в папке `release/`.

Для разработки:

```bash
yarn electron:dev
```
